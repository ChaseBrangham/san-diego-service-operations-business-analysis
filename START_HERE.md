# Start Here

This repository has two layers.

## 1. Read the case study first

Open **`START_HERE_Master_Business_Analysis_Case_Study.pdf`** for the complete end-to-end narrative.

Then read **`README.md`** for the GitHub-facing version with direct links to every artifact and the companion Power BI dashboard.

## 2. Review the supporting BA artifacts

The detailed files are organized by function:

- `docs/` - project framing and scope
- `stakeholders/` - stakeholder register, power/interest analysis, engagement plan
- `process-maps/` - current-state and proposed future-state workflows, including editable diagrams.net source files
- `process-analysis/` - current-state findings, gap analysis, root-cause hypotheses
- `requirements/` - requirements, stories, KPI/data dictionary, business/data rules, prioritization
- `traceability/` - requirement-to-solution-to-test traceability
- `testing/` - UAT planning and analyst solution verification
- `evaluation/` - solution evaluation and recommendations
- `project-management/` - decisions, assumptions, sources, RAID
- `implementation/` - ownership, rollout, governance, adoption, change control
- `reflection/` - lessons learned and live-engagement next steps
- `jira/` - Jira-ready backlog and import notes
- `solution-evidence/` - implementation and dashboard evidence register
- `sources/` - public references, companion analytics README, evidence boundaries
- `previews/` - GitHub-friendly images of spreadsheet artifacts

## Important portfolio disclosure

This is a simulated BA engagement based on public City of San Diego data and a completed Power BI project. It does not claim City stakeholder interviews, internal access, approved requirements, formal UAT, or City acceptance.
